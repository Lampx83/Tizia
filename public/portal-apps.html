Cài app SPA chuẩn AI Portal vào Tizia. Đóng gói .zip chứa manifest.json + public/index.html rồi kéo thả vào đây. App của bạn được serve dưới /portal-apps/u/<id>/<alias>/ và xuất hiện trong trang Ứng dụng. Lần đầu làm app? Đọc hướng dẫn phát triển →

📥 Cài app mới .zip

📋 Quy chuẩn manifest.json

Bắt buộc alias (lowercase kebab, ví dụ my-app) + name. App cần backend riêng thì khai thêm hasBackend: true + apiProxyTarget (URL tuyệt đối tới dịch vụ của bạn) — xem mục 5 của hướng dẫn. Code backend nằm trong zip thì KHÔNG được chạy. 

{
  "id": "my-app",
  "alias": "my-app",
  "name": "My App",
  "description": "Mô tả ngắn về app",
  "icon": "🎨",
  "version": "1.0.0",
  "type": "embedded",
  "hasFrontendOnly": true
}

Cấu trúc zip:

my-app.zip
├── manifest.json
└── public/
    ├── index.html      ← bắt buộc (entry point)
    ├── embed-config.json   ← tuỳ chọn, tự sinh nếu thiếu
    └── assets/...      ← JS/CSS đã build (đường dẫn TƯƠNG ĐỐI: ./assets/...)

⚠️ Trong index.html, mọi đường dẫn asset phải tương đối (./assets/...), KHÔNG dùng /assets/... tuyệt đối — vì app chạy dưới /portal-apps/u/<id>/<alias>/. Với Vite: vite.config.js set base: './'.
