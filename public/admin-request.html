Quay về code cũ có làm mất dữ liệu không?

Quay về phiên bản code trước giữ nguyên schema đã mở rộng và mọi dữ liệu đã ghi. Code cũ chỉ sửa các trường nó biết.

Hoàn tác dữ liệu là thao tác riêng theo revision. Xóa trường, đổi kiểu hoặc sửa schema dùng chung phải dừng để duyệt migration; Git revert không tự hoàn tác database.
